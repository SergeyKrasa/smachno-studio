# Smachno Studio — сайт студии

Сайт кулинарной студии Smachno: книга рецептов с фото, видео и пошаговыми инструкциями, статьи «Наука вкуса и здоровья» и страница о студии.

Сайт статический: никаких баз данных и WordPress, он бесплатно работает на GitHub Pages.

## Что умеет сайт

- **Книга рецептов** с фильтром по разделам и поиском по названию и ингредиентам.
- **Страница рецепта**: ингредиенты с галочками (сайт запоминает, что уже отмечено), пересчёт порций, шаги, видео, кнопка «Распечатать».
- **Режим готовки**: шаги крупно на весь экран, листаются свайпом или стрелками. Экран телефона не гаснет. Если в шаге есть время («варить 20 минут»), по нажатию запускается таймер, а по готовности он звенит, как эмалированная миска.
- Видео с YouTube подгружаются только по нажатию, поэтому страницы открываются быстро.
- Разметка рецептов для Google: в поиске рецепт может показываться с фото и временем приготовления.

## Как добавить или изменить рецепт

Все тексты лежат в папке `content/`:

| Файл | Что внутри |
|---|---|
| `content/recipes.json` | рецепты |
| `content/articles.json` | статьи «Наука вкуса» |
| `content/videos.json` | ролики для блока видео на главной |
| `content/site.json` | название, слоган, почта, ссылки, отзывы, текст «О студии», рецепт дня |

Рецепт выглядит так:

```json
{
  "slug": "blinchiki-s-krasnoy-ryboy",
  "title": "Королевские блинчики с красной рыбой",
  "category": "snacks",
  "description": "Короткое описание в одну-две фразы.",
  "time": "1 час",
  "minutes": 60,
  "servings": 4,
  "image": "blinchiki-s-krasnoy-ryboy",
  "video": "ID-ролика-с-YouTube",
  "ingredients": [
    { "title": "Для блинов", "items": [
      { "name": "Молоко", "amount": 300, "unit": "мл", "note": "" },
      { "name": "Соль", "amount": null, "unit": "по вкусу", "note": "" }
    ] }
  ],
  "steps": [
    { "title": "Замешивание основы", "text": "Смешайте муку и яйца… Оставьте тесто на 20 минут.", "t": 15 }
  ],
  "tips": ["Совет студии."]
}
```

- `slug` — адрес страницы, латиницей через дефис.
- `category`: `main` (основные блюда), `salads` (салаты), `snacks` (закуски), `desserts` (десерты), `drinks` (напитки).
- `image` — имя фото без окончания. Положите в `src/img/dishes/` файл `имя-800.jpg` (ширина 800 px) и, если есть, `имя-1600.jpg` (ширина 1600 px).
- `video` — то, что стоит после `v=` в ссылке на ролик.
- `amount` — число: при смене количества порций оно пересчитается само. `note` — пояснение мелким шрифтом.
- В шаге `t` — секунда видео, с которой начинается этот шаг (необязательно). Появится кнопка «Смотреть этот шаг». К шагу можно добавить фото: `"image": "имя-файла"` (файл `src/img/steps/имя-файла-800.jpg`).
- Время в тексте шага («20 минут», «1,5 часа») само превращается в кнопку таймера.
- **Рецепт дня** на главной меняется сам каждый день: рецепты идут по кругу. Чтобы всегда показывать один рецепт, поставьте `"rotateRecipeOfDay": false` и впишите его `slug` в поле `recipeOfDay` в `content/site.json`.

## Как обновить сайт

Сайт пересобирается **сам**: при каждом изменении в репозитории GitHub запускает сборку (вкладка **Actions**), и через 1–2 минуты новая версия появляется в интернете.

Самый простой способ — править прямо на github.com: откройте файл (например, `content/recipes.json`), нажмите карандаш ✏️, внесите изменения и нажмите **Commit changes**. Фото загружаются кнопкой **Add file → Upload files** в папку `src/img/dishes/`.

Если работаете на своём компьютере, понадобится [Node.js](https://nodejs.org) версии 18 или новее. Собрать сайт и посмотреть его до публикации:

```bash
node build.mjs
npx serve docs
```

Затем отправьте изменения: `git add . && git commit -m "Новый рецепт" && git push`. Папка `docs/` в репозиторий не попадает: GitHub собирает её сам.

## Свой домен

Чтобы сайт открывался по адресу smachnostudio.com, впишите домен в поле `domain` в `content/site.json`, пересоберите сайт и укажите домен в настройках репозитория: **Settings → Pages → Custom domain**. Затем у регистратора домена направьте его на GitHub Pages. Также поменяйте `url` в `site.json` на новый адрес.

## Устройство

- `build.mjs` — сборщик без внешних зависимостей.
- `tools/photo.mjs` — подготовка фото: `npm install` один раз, затем `node tools/photo.mjs фото.jpg dishes имя-рецепта`.
- `CLAUDE.md` — памятка для Claude: попросите его по-русски, что изменить на сайте, и он сделает это по этим правилам.
- `src/css/site.css` — оформление («Звёздная эмаль»: кобальтовая эмаль в крапинку, белая эмаль, золото логотипа).
- `src/js/site.js` — фильтр рецептов, видео, таймеры, режим готовки.
- `src/fonts/` — шрифты Prata и Onest (лицензия SIL Open Font License).
- `DESIGN.md` — описание дизайн-системы, `PRODUCT.md` — о проекте.
