# Chef's Challenge — первый рабочий прототип

Страница: /games/chef-challenge/

## Что реализовано
- Первый игровой уровень: греческий салат.
- Сетка 6×6: 27 фотореалистичных плиток вокруг центральной салатницы.
- 8 обязательных ингредиентов и 19 отвлекающих продуктов.
- Название продукта: при наведении мышью; на сенсорном экране — пока палец удерживается на продукте. При отпускании надпись исчезает.
- Можно перетаскивать продукт в салатницу или нажать продукт, а затем салатницу.
- Любой порядок добавления ингредиентов.
- Нет кнопки очистки, подсказок или списка правильных ингредиентов.
- Проверка только по кнопке «Готово».
- При ошибке — только дружелюбный смайлик и «Попробуйте ещё раз!»; выбранные продукты сбрасываются.
- При успехе — поздравление, звёзды и очки.
- Локальное сохранение текущего хода в браузере.
- Музыка и звуковые эффекты с отдельными переключателями.

## Важные оговорки прототипа
- Пока интерактивен только уровень 1; уровни 2–10 показаны как закрытые.
- Очки в коде — тестовые значения: база 1000, бонус первой/второй/третьей попытки 500/300/150; звёзды 3/2/1. Перед выпуском всей десятки их можно утвердить окончательно.
- Счётчики в окне статистики локальные, только для текущего браузера. Глобальная статистика всех посетителей потребует серверного хранилища; её нельзя достоверно получить только из статического GitHub Pages.
- Все визуальные изображения встроены в HTML как WebP data URI, поэтому отдельные файлы ассетов для этой страницы не нужны.
