# Сайт Smachno Studio — памятка для Claude

## С кем ты работаешь
Владелец сайта — Сергей, автор кулинарного YouTube-канала **Smachno Studio**. Он не программист. Говори с ним по-русски, просто и коротко, без технических слов (не «коммит» и «деплой», а «сохранить» и «опубликовать»). Если просьба неясна, задай один-два уточняющих вопроса с вариантами ответа.

**Перед публикацией** всегда показывай, что изменится (скриншот или страницу в браузере), и спрашивай: «Публикуем?». Публикуй только после его «да».

## Что это за сайт
- Адрес: https://sergeykrasa.github.io/smachno-studio/
- Репозиторий: https://github.com/SergeyKrasa/smachno-studio, ветка `main`.
- Статический сайт без зависимостей: `node build.mjs` собирает `content/*.json` и `src/` в папку `docs/`.
- Публикация автоматическая: после `git push` в `main` GitHub Actions (`.github/workflows/pages.yml`) собирает сайт и выкладывает его на GitHub Pages за 1–2 минуты. Папку `docs/` в git не добавляй, она в `.gitignore`.
- Язык сайта — русский. Названия роликов на YouTube часто на украинском. На сайте их пишем по-русски.

## Где что лежит
| Что | Где |
|---|---|
| Рецепты | `content/recipes.json` |
| Ролики для видеоленты на главной | `content/videos.json` |
| Статьи «Наука вкуса» | `content/articles.json` |
| Название, слоган, почта, YouTube, отзывы, «О студии», рецепт дня | `content/site.json` |
| Фото | `src/img/dishes/` (главные), `src/img/steps/` (шаги), `src/img/articles/`, `src/img/about/` |
| Оформление | `src/css/site.css`; правила дизайна — в `DESIGN.md` |
| Поведение (фильтр, таймеры, режим готовки) | `src/js/site.js` |
| Шаблоны страниц | `build.mjs` |

## Команды
```bash
npm install                  # один раз, нужен только для подготовки фото
node build.mjs               # собрать сайт в docs/
npx --yes serve@14.2.4 docs  # посмотреть локально: http://localhost:3000
node tools/photo.mjs <файл> <dishes|steps|articles|about> <имя> [--crop-right N]   # подготовить фото
gh run watch                 # следить за публикацией после git push
```

## Рецепт: формат
```json
{
  "slug": "borshch",                       // адрес: /recepty/borshch/ — латиницей через дефис, уникальный
  "title": "Борщ с пампушками",
  "category": "main",                      // main | salads | snacks | desserts | drinks
  "description": "1–2 фразы для карточки и первого экрана.",
  "intro": ["Абзац вступления от автора (можно [ссылку](/recepty/slug/) и **жирный**)."],
  "heroLines": ["Борщ", "с пампушками"],    // как разбить заголовок на строки на главной
  "heroAccent": "с пампушками",            // кусок последней строки, который станет золотым
  "time": "1 ч 30 мин", "minutes": 90, "prepMinutes": 30, "cookMinutes": 60,
  "servings": 6,                           // число — тогда работает пересчёт порций
  "calories": 210,                         // на порцию; если неизвестно — null
  "image": "borshch",                      // файлы src/img/dishes/borshch-800.jpg (+ -1600, .avif)
  "imageAlt": "Описание фото для незрячих",
  "video": "ID_ролика",                    // часть ссылки после v= ; если ролика нет — null
  "published": "2026-10-12",
  "ingredients": [
    { "title": "Для бульона", "items": [   // title может быть null, если группа одна
      { "name": "Говядина на кости", "amount": 500, "unit": "г", "note": "" },
      { "name": "Соль", "amount": null, "unit": "по вкусу", "note": "" }
    ] }
  ],
  "equipment": [{ "name": "Кастрюля 4 л", "note": "" }],
  "steps": [
    { "title": "Бульон", "text": "Залейте мясо водой и варите 1,5 часа.", "t": 35,
      "image": "borshch-step-1", "imageAlt": "…" }   // t (секунда видео) и image — необязательны
  ],
  "tips": ["**Секрет:** текст совета."]
}
```
- `amount` — число (0.5, а не «1/2»), иначе не сработает пересчёт порций.
- Время в тексте шага («20 минут», «1,5 часа», «полчаса») само становится кнопкой таймера.
- `t` — секунда ролика, с которой начинается шаг. Появится кнопка «Смотреть этот шаг».
- Новый рецепт с роликом добавь и в `content/videos.json`: `{ "id", "title", "recipe": "slug", "duration": секунды, "uploadDate": "ГГГГ-ММ-ДД" }`. Свежие ролики ставь в начало массива.
- **Рецепт дня** меняется сам каждый день (`rotateRecipeOfDay: true` в `site.json`).

## Как выполнять типичные просьбы
- **«Добавь рецепт»**: возьми текст и фото у Сергея. Если он дал ссылку на ролик YouTube, название и описание возьми по ссылке (`https://www.youtube.com/oembed?url=…&format=json` и страница ролика) и переведи на русский. Чего не хватает (количества, порции, время), спроси у него, а не придумывай. Фото прогони через `tools/photo.mjs`.
- **«Исправь текст / опечатку»**: найди строку в `content/`, поменяй, покажи было/стало.
- **«Поменяй фото»**: `tools/photo.mjs` с тем же именем перезапишет файлы.
- **«Добавь статью»**: формат в `content/articles.json` (`slug`, `title`, `lead`, `image`, `body` — абзацы-строки и блоки `{"h2"}`, `{"h3"}`, `{"ul": []}`).
- **Удаление** рецепта или статьи — только после явного подтверждения.

## Проверка перед публикацией
1. `node build.mjs` без ошибок.
2. Открой страницу локально (`npx --yes serve@14.2.4 docs`) и посмотри её на ширине компьютера и телефона: ничего не вылезает за край, фото на месте, кнопки работают.
3. Покажи Сергею, получи «да».
4. `git add -A && git commit -m "<что сделано, по-русски>" && git push`, затем `gh run watch` и открой живую страницу.

## Правила
- **Не придумывай факты:** ни отзывов, ни цифр (подписчики, количество рецептов), ни калорий, ни времени готовки. Только то, что дал Сергей или что есть в его роликах.
- **Сохраняй дизайн «Звёздная эмаль»** (`DESIGN.md`): кобальт в крапинку, белые эмалевые подносы с тёмным ободком, золото, шрифты Prata и Onest, томатный цвет только для видео и таймеров. Новые элементы делай в этом же стиле. Большие изменения дизайна обсуждай заранее.
- Не используй эмодзи в текстах сайта, иконки рисуются в `src/icons.mjs`.
- Никогда не клади пароли и ключи в файлы репозитория.
- Если `git push` не проходит, проверь `gh auth status`.
