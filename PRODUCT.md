# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/vanilla JS generated by a dependency-free Node script (`build.mjs`) from JSON content; output in `docs/`, served by GitHub Pages. Chosen by the builder (user delegated: "полноценный сайт", hosted on GitHub Pages, repo to be handed over to the studio owner, so no framework or build service to maintain).

## Users

Russian-speaking home cooks who follow the Smachno Studio YouTube channel or arrive from search. They browse recipes on the sofa (tablet/laptop) and cook from a phone propped up on the kitchen counter, hands busy, screen at arm's length. Many are 35+; testimonials name families, children's birthdays and holiday tables.

## Product Purpose

Smachno Studio ("Студия кулинарных шедевров Smachno") publishes home recipes with photos, step-by-step instructions, accessible ingredients and a YouTube video for each dish. Tagline: «Smachno Studio — твоё вдохновение на кухне. Готовим просто, едим с удовольствием!» The site is the recipe book behind the channel. Success means two things, weighted equally: visitors cook a dish from the site, and they subscribe to / watch the YouTube channel.

## Brand Commitments

- Name: Smachno Studio. The site is signed by the studio, not by a person (owner's choice).
- Logo: a night-sky cobalt circle with stars and a pale-gold serif "S" + italic "machno". Preserve it as is.
- Contact: smachnostudio@gmail.com. YouTube: https://www.youtube.com/@SmachnoStudio
- Language: Russian.

## Content Truth

- Recipes, articles («Наука вкуса и здоровья»), testimonials and the About text come from the existing site smachnostudio.com (owner's own content).
- No invented numbers: the old site's counters showed 0, so no subscriber/recipe statistics are shown.
- The old site had a WPForms newsletter; a static site cannot process it, so subscription is via YouTube and contact via e-mail.

## Open decisions

- Custom domain (smachnostudio.com) could later point to GitHub Pages; not done now.
